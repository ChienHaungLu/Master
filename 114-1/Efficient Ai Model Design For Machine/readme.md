# EFFICIENT AI MODEL DESIGN FOR MACHINE LEARNING AND INFERENCE
本課程主要聚焦在模型壓縮的部分,特別是Lab2-Lab6的作業更聚焦在本門課所著重之模型壓縮主題

<br>

## Lab1
此作業主要透過ResNet18來作為模型框架,並且完成NN分類器用於手寫數字分類任務中

<br>

## Lab2
此作業主要在做模型的剪枝,其核心概念是透過對網路不常使用的權重、channel、神經元、Layer將其減去,使模型變小,後續透過適當訓練來近似原始模型應有的準確率

<br>

## Lab3
主要在做量化,量化一詞可以想成是將一個絕對的概念以數值的方式呈現,若將模型部屬在硬體上,為了減少功耗或硬體成本，可能會需要透過損失一些精度/效能來達成(例如:FP32轉INT8)


<br>

## Lab4
主要在做知識蒸餾, 透過將較大的模型所學到的知識轉移至較小模型(一般常見的框架為Teacher-Student),比起其他的剪枝和量化等模型壓縮技術是對模型本身做修改,知識蒸餾更像是對模型訓練過程中的一種改善技巧，考量運算資源的成本、效能及硬體設備上的限制，我們可能可以透過知識蒸餾得到一些較輕量級的模型。

<br>

## Lab5
本作業主要使用ONNX提供深度學習的模型可以跨平台或跨框架在不同環境或裝置進行部屬, 其中會使用到ONNX Quantization，目的在於為了加速推論、減少記憶體使用量及降低模型大小，作業是使用INT8對模型權重進行量化，最後透過Gradio建立互動式機器學習模型或應用的網頁介面，用於網頁的部署供他人展示、分享等

<br>

## Lab6
本作業主要分兩大部分,第一部分主要針對Vision Transformer進行Pruning,剪枝原因在於計算attention的計算量會隨token數量而呈現次方級別成長,考慮資源有限下必須做壓縮降低運算量,剪枝一般是減去不常使用的token。第二部分則是針對Vision Transformer進行對權重及activations同步做INT8量化,好處是可以使模型推論加速並節省記憶體使用空間
